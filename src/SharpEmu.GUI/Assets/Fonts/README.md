# Material Symbols

`MaterialSymbolsRounded-400.ttf` is derived from the `material-symbols` npm
package, version `0.45.8`.

The package's Rounded WOFF2 variable font was instantiated at:

- `FILL=0`
- `wght=400`
- `GRAD=0`
- `opsz=24`

It was converted to a static TTF because Avalonia supports embedded TTF/OTF
fonts but does not support variable fonts. The upstream Apache-2.0 license is
included in `LICENSE.material-symbols.txt`.

Source: https://www.npmjs.com/package/material-symbols
